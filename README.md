# REWRITE — Snow on my boots

An interactive excerpt from Ian Rosenthal’s original manuscript. Readers move through ten moments at their own pace, with gentle snow, comic-book textures and optional synthesized sound.

## Use the scene

Click the main button or illustrated door to continue. Use the arrows or timeline to revisit a moment. Sound starts off. Motion can be switched off. “Read the excerpt” opens the dialogue in a plain reading view.

## Run locally

Open `dist/index.html` in a modern browser. There is no installation or build step.

## Source

- `dist/index.html`: page structure and the SVG doorway drawing.
- `dist/styles.css`: responsive layout, typography, comic textures and animation.
- `dist/app.js`: story beats, controls, snow and synthesized audio.
- `dist/favicon.svg`: browser-tab icon.

The site uses plain HTML, CSS and JavaScript without external dependencies, analytics or music files.
